# Иконки интерфейса

SVG предоставлены пользователем из Materials/170-thin-line-ui-icons/svg-single. Скопированы только используемые файлы, без изменения исходных контуров. Цвет в интерфейсе применяется через CSS mask/currentColor, поэтому иконки следуют системной теме. Эти файлы не генерировались ИИ.

`paste_icon.svg` предоставлен пользователем отдельно с Desktop; скопирован без изменения исходных контуров. `126__cash.svg` взят из той же папки svg-single.

`049__mail.svg` взят из той же папки svg-single для кнопок сообщения о проблеме через GitHub Issues.
