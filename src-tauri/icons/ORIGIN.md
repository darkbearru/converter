# Значок Converter

Оригинал — корневой `book.svg`, предоставленный пользователем и выбранный им для значка Converter. Этот же файл используется в заголовке приложения. Рисунок сохранён без изменения; при растеризации он вписан в квадрат с прозрачными полями.

PNG, ICNS и ICO получены официальной командой `@tauri-apps/cli 2.12.3`:

```sh
npm run tauri -- icon book.svg --fit contain --output .work/generated-book-icons
```

В приложение скопированы только desktop-файлы: 32×32, 128×128, 256×256, icon.png, icon.icns и icon.ico. В PNG встроена запись происхождения. Промежуточные мобильные изображения не включены в приложение; SDK мобильных платформ не устанавливались.
