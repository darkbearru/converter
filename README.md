# Converter

[Описание и скачивание для macOS и Windows](https://darkbearru.github.io/converter/)

Локальный конвертер Lingvo DSL в бинарные словари MDict v2: **MDX + MDD** с изображениями, озвучкой и оформлением. Tauri 2, Vue 3/TypeScript, Rust. Для работы собранного приложения PHP, Python и Node.js не требуются.

Готовые установщики для macOS Apple Silicon и Windows x64 доступны в [релизах GitHub](https://github.com/darkbearru/converter/releases). Сборки для macOS Intel временно исключены из автоматического выпуска; при необходимости их можно собрать отдельно.

Источники: `.dsl`, `.dsl.dz`, ZIP, локальные ресурсы и прямые HTTP(S)-ссылки. Скачивание поддерживает контрольные точки, паузу, ограниченные повторы и продолжение через Range/If-Range. Все источники задания должны скачаться и пройти проверку до конвертации. Завершённые файлы повторно используются из кэша.

Интерфейс на PrimeVue следует системной светлой/тёмной теме. Нижняя панель принимает файлы и ссылки; скачанный словарь ждёт отдельного запуска конвертации. Активные задачи поднимаются над панелью, завершённые переходят в Accordion с файлами, предупреждениями и кнопкой открытия папки. При неизвестном размере процент отсутствует. Результат публикуется целой папкой с MDX, MDD и `conversion-report.json`; существующие файлы сохраняются, совпадения получают суффикс.

Предупреждения объединяются по причине и источнику с сохранением числа употреблений; полный журнал доступен отдельно. Кнопки «Сообщить о проблеме» открывают заполненную форму GitHub Issues с версией, ОС и краткой диагностикой выбранной задачи. Пользователь проверяет текст и отправляет сообщение из своего аккаунта; полный JSON-отчёт прикладывается вручную.

При запуске Converter один раз проверяет последний обычный релиз GitHub и предлагает скачать новую версию. В меню «О программе» доступны текущая версия и ручная проверка обновлений. Кнопка «Скачать» открывает страницу релиза в браузере; установка выполняется пользователем. Проверка работает без GitHub-аккаунта и токена, сбой сети не мешает конвертации. Черновики, предварительные релизы и версии старше установленной не предлагаются.

Основные платформы — **macOS и Windows x64**. iOS/Android вынесены в следующий этап: мобильные SDK и сборки пока не устанавливаются и не проверяются.

## Запуск разработки

Node.js 24.18.0, npm 12.2.0, Rust 1.99.1 из `rust-toolchain.toml`, системные desktop инструменты сборки.

```sh
npm ci
npm run tauri -- dev
```

## Сборка и проверки

```sh
npm test -- --run
npm run typecheck
npm run check:contracts
npm run test:e2e
cargo test --locked --workspace --all-targets
cargo clippy --locked --workspace --all-targets -- -D warnings
```

Для Playwright предварительно выполнить `npx playwright install chromium webkit`. Linux CI проверяет библиотеки с `--exclude converter-desktop`; Linux-приложение в выпуск не входит.

```sh
npm run build:macos
npm run build:windows
```

Каждая команда запускается на соответствующей ОС. Пакеты и `build-info.json`/`SHA256SUMS` находятся в `.work/packages/<target>/`. CI [Desktop packages](https://github.com/darkbearru/converter/actions/workflows/desktop.yml) собирает macOS Apple Silicon и Windows x64 и сохраняет артефакты, не публикуя release. Подпись Developer ID и notarization оформляются отдельно. Отдельная сборка Intel описана в [инструкции macOS](docs/build/macos.md).

## Структура

| Модуль | Ответственность |
|---|---|
| `converter-core` | Подготовка источников, реестр читателей, DSL, внешняя сортировка, MDX/MDD, валидация |
| `converter-download` | HTTP, приватный кэш, контрольные точки, SHA-256, повторы и продолжение |
| `converter-app` | Очередь, состояния, события, журнал и платформенное хранилище |
| `src-tauri` | Нативные диалоги, ограниченный IPC и жизненный цикл окна |
| `src` | Vue-интерфейс, типы DTO и bridge |
| `converter-cli` | Инструмент разработки для проверки локального/URL-конвейера |

В первой версии реальный читатель один — DSL. Новые форматы добавляются разработчиком через `DictionaryReader`, регистрацию в `FormatRegistry` и пересборку. Загружаемых исполняемых плагинов нет. Системные диалоги и список форматов используют реестр.

Тесты используют собственные синтетические словари. Для приёмки конкретной пользовательской базы нужны её исходные файлы и ресурсы; результаты и границы текущего покрытия перечислены в протоколах выше.

## Языки приложения и сайта

Converter поддерживает русский и английский. На первом запуске используется основной язык ОС; для неподдерживаемого языка выбирается английский. Ручной выбор в «О программе → Язык» / «About Converter → Language» сохраняется отдельно от задач.

Тексты приложения и нативных действий: `locales/ru.json`, `locales/en.json`. Новые ошибки Rust передают `message_key` и `message_args`; старые журналы без них показывают исходный текст. Для составных DSL поддерживается `#INCLUDE`: части рядом с исходником или внутри ZIP объединяются в один результат. Зашифрованные ZIP (ZipCrypto/AES) запрашивают пароль при подготовке; пароль не сохраняется в истории. Литерал `@` в сообщении Vue I18n записывается как `{'@'}`.

Тексты страницы проекта: `website/locales/ru.json`, `website/locales/en.json`; разметка и стили общие — `website/index.html`, `website/style.css`. Публикуются `/ru/` и `/en/`; корень выбирает основной язык браузера либо сохранённый выбор, с английским fallback. Без JavaScript доступны английская страница и прямые установщики. Версия и ссылки заполняются существующим workflow из последнего стабильного релиза.

Ссылки поддержки находятся в `config/locales.json`: RU использует CloudTips, EN — Hipolink; значение `null` скрывает поддержку для соответствующего языка. Изменение адреса попадёт на сайт при следующем deploy, в приложение — при следующей сборке.
