# Происхождение изображения

`interface.jpg` — снимок настоящего Vue-интерфейса Converter из `tests/ui/harness/index.html?capture=1&scenario=succeeded`, 1280×720, тёмная системная тема, раскрыто задание `main.dsl`. Снимок получен инструментом браузера 19 октября 2026 года.

Словарь, число статей, размеры и ресурсы в кадре синтетические, из тестового harness. Пользовательские словари, локальные пути и история не использовались. На странице снимок подписан как пример интерфейса. Генеративная графика и сторонние фотографии не применялись. Книга — предоставленный пользователем `book.svg`; значок загрузки — существующий `src/assets/icons/027__download.svg`, происхождение набора указано в `src/assets/icons/ORIGIN.md`.

Этот файл не включается в публичную сборку страницы.

## English interface (localization)

`interface-en.jpg` is a 740×500 Chromium capture of the running Vue application with `lang=en`, light system theme and the `localized-preview` harness scenario. Dictionary names, entry counts and warnings are synthetic. It is captured from the application's actual components and CSS; no source dictionary content or private file paths are included.

The English capture was refreshed on 2026-10-19 after configuring Hipolink support; the header now includes the same donation icon as the running application.
