## Русский

- Русский и английский интерфейс приложения и страницы проекта. Основной язык системы выбирается автоматически, для остальных языков используется английский. Ручной выбор сохраняется в «О программе».
- Отдельные ссылки поддержки для русской и английской версий.
- Зашифрованные ZIP (ZipCrypto и AES) запрашивают пароль с возможностью повторного ввода. Пароль не записывается в историю, настройки и отчёт.
- Поддержка составных DSL через `#INCLUDE`: соседние части словаря или части внутри ZIP объединяются в один результат.
- Более терпимая обработка абзацных тегов `[mN]`: отсутствие явного закрытия и повторный сброс отступа не останавливают конвертацию.
- Привычное отображение путей Windows и исправленные пробелы в счётчиках скачивания.

**Установщики:** macOS Apple Silicon — `Converter_0.3.0_aarch64.dmg`; Windows x64 — `Converter_0.3.0_x64-setup.exe`. PHP, Python и Node.js для работы приложения не нужны. Сборки macOS Intel пока не выпускаются.

## English

- Russian and English interfaces for the app and product website. The primary system language is detected automatically, with English as the fallback. A manual choice can be saved in About Converter.
- Separate support links for each language.
- Password-protected ZIP archives (ZipCrypto and AES), including password retries. Passwords are kept in memory and excluded from history, settings and reports.
- Multi-part DSL dictionaries using `#INCLUDE`: nearby files or parts within the same ZIP are combined into one result.
- More tolerant handling of `[mN]` paragraphs: implicit paragraph endings and repeated indent resets no longer stop conversion.
- Cleaner Windows paths and correctly spaced download counters.

**Installers:** macOS Apple Silicon — `Converter_0.3.0_aarch64.dmg`; Windows x64 — `Converter_0.3.0_x64-setup.exe`. No PHP, Python or Node.js runtime is required. macOS Intel builds are currently excluded.
