## Русский

- Исправлена видимость готовых словарей в Finder: папка и файлы результата больше не остаются скрытыми. Ранее созданные результаты становятся видимыми при открытии папки из приложения.
- Кнопка «Скачать» в уведомлении об обновлении и в «О программе» открывает установщик показанной версии для текущей ОС и архитектуры: DMG для macOS Apple Silicon или EXE для Windows x64.
- На странице продукта основная кнопка скачивания соответствует системе посетителя. Остальные варианты доступны по ссылке «Другие системы»; на телефонах, Linux и неизвестных системах сразу видны оба варианта.

**Установщики:** macOS Apple Silicon — `Converter_0.3.1_aarch64.dmg`; Windows x64 — `Converter_0.3.1_x64-setup.exe`. PHP, Python и Node.js для работы приложения не нужны. Сборки macOS Intel пока не выпускаются.

## English

- Fixed converted dictionaries appearing hidden in Finder. Output folders and files are made visible when conversion finishes. Existing results regain visibility when their folder is opened from the app.
- Download in the update notification and About dialog opens the installer for the displayed version and current OS and architecture: DMG for macOS Apple Silicon or EXE for Windows x64.
- The product website highlights the download for the visitor's operating system. Other installers are available under Other systems; phones, Linux and unknown systems show both choices immediately.

**Installers:** macOS Apple Silicon — `Converter_0.3.1_aarch64.dmg`; Windows x64 — `Converter_0.3.1_x64-setup.exe`. No PHP, Python or Node.js runtime is required. macOS Intel builds are currently excluded.
