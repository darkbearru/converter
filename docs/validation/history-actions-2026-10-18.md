# Предупреждения и очистка истории — 18.10.2026

Проверено по запросу пользователя и снимку приложения от 14:35:13. Существующий рабочий стол, тема, иконки и пропорция истории/панели источника сохранены.

## Причина предупреждения

В сохранённом результате PhoneticListChCh.dsl.dz статус соответствует данным: 22 949 статей, 22 949 ключей, 1 ресурс, **28 173 предупреждения** `missing_reference`. Счётчик в снимке задания, число строк журнала и summary отчёта совпадают. Пример: «Не найдена статья для ссылки: 儿». Проверка была только для чтения; исходный словарь и пользовательский результат не изменялись.

Причина отсутствия объяснения на экране — свёрнутый журнал под результатом и действиями. Теперь первое предупреждение, его источник и строка видны сразу при раскрытии записи, перед результатом. Кнопка «Показать все» открывает журнал страницами по 50 записей. Предпросмотр загружает одну запись; десятки тысяч сообщений не попадают в DOM одновременно. Ошибка чтения журнала не выдаётся за отсутствие предупреждений.

## Поведение истории

- «Открыть папку результата», «Сохранить копию», «Повторить», «Удалить» расположены одной строкой. Путь результата остаётся активным отдельно под ними.
- «Удалить» открывает Dialog с текстом «Вы действительно хотите удалить», именем словаря, пояснением о сохранности файлов и кнопками «Отмена» / «Удалить».
- Подтверждение удаляет только запись истории и её диагностический журнал. Исходники, загрузочный кэш и готовые MDX/MDD/отчёт остаются на диске. Список остаётся очищенным после перезапуска.
- Выполняемое задание удалить нельзя. Работник завершает выход перед удалением. Сохранение копии защищено от параллельного удаления и повторного экспорта.
- При ошибке удаления запись сохраняется. Запоздалые события не возвращают уже удалённую запись. Во время удаления Dialog не закрывается через Escape; ответ операции применяется только к соответствующей записи.
- После удаления последней записи пустая панель источника вновь занимает 100% свободного пространства.
