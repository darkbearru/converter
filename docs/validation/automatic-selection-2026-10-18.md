## Поведение и восстановление

DSL-читатель получает названия и явные межсловарные связи, исключая комментарии, экранированные теги и `_abrv`. Литералы внутри `<<…>>` пропускаются общим с renderer правилом поиска конца ссылки с учётом экранирования, поэтому текст тега внутри такой ссылки не создаёт зависимость. Единственный однозначный конечный адресат связанной группы становится основным. Неоднозначность, отсутствующая база-цель, повторяющиеся #NAME, цикл, отсутствие связей, нечитаемая база или неподдерживаемый анализ возвращают прежний ручной выбор; сохранённый ручной выбор имеет приоритет.

Основная конвертация не ждёт Dialog «Другие словари в архиве». Он перечисляет независимые базы и предлагает «Пропустить» / «Конвертировать». Согласие создаёт отдельные задания с собственными UUID, прогрессом, отчётом, результатом и повтором; очередь остаётся последовательной. Они наследуют кодировку, ресурсы и папку, сохраняя метаданные собственной базы.

Обычное закрытие/Escape и «Пропустить» сохраняют отказ. На время сохранения кнопки, крестик и Escape блокируются. ID дочерних заданий выделяются заранее и сохраняются с решением: повтор согласия не создаёт дублей; незавершённый принятый план восстанавливается при перезапуске, ранее созданные и позднее удалённые задания повторно не создаются.

Ошибка сохранения оставляет предложение для повтора даже при очищающем его событии родительского задания. «Закрыть» после ошибки локально скрывает окно, позволяя продолжить работу с основным, без второй команды решения. Несохранённое предложение может появиться на следующем запуске; уже принятый план восстанавливается по сохранённым данным.

Одиночный локальный/URL-файл не ищет соседей. URL принимает архив либо один словарь. Поиск в исходной папке, объединение баз и общая переносимость межсловарных переходов остаются вне реализации.

После code review добавлена проверка изменившегося источника. Автоматически выбранный основной и планы дочерних заданий сохраняют SHA-256 соответствующего файла словаря внутри архива. Перед чтением после нового извлечения хеш сверяется; замена/перестановка членов перепакованного архива не приводит к незаметной конвертации другой базы по старому порядковому ID. При несовпадении возвращается `source_changed`: «Словарь в архиве изменился после анализа. Выберите архив заново». Эта граница и пропуск литералов проверены отдельными RED→GREEN тестами после исходного функционального среза.

## Решения при реализации

- Работа продолжена в существующем develop; независимые правки parser/backend делегированы с разными файлами, интеграция и итоговые исправления выполнены родителем. Цена ошибочной границы — конфликт изменений; итоговая матрица и единое ревью проверили интеграцию.
- Автоматически выбирается только единственный конечный адресат ациклического графа; изолированные базы требуют согласия. При неоднозначности остаётся ручной выбор. Цена консервативного решения — дополнительный выбор в менее очевидном пакете.
- Объединение и поиск соседних файлов не включены в эту доработку; URL остаётся архивом либо одним словарём. Цена ограничения — внешняя база за пределами пакета автоматически не подключится.
- После ошибки сохранения Dialog можно закрыть локально без второй команды решения. Цена — несохранённое предложение может повториться после перезапуска; сохранённый принятый план восстанавливается независимо.
- Нативная проверка, отложенная code reviewer до доставки, выполнена исполнителем отдельно. Она подтверждает новый сценарий macOS; остальные платформы и читалки остаются отдельной приёмкой.
