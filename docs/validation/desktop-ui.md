# Проверка Vue-интерфейса

Дата: 2026-10-18. Vue/Vitest: 14 тестов. Playwright: 28 сценариев (7 × 4 конфигурации).

| Конфигурация | Размер viewport | Результат |
|---|---:|---:|
| Chromium desktop | 1280 × 800 | 7/7 |
| WebKit desktop | 1280 × 800 | 7/7 |
| Chromium narrow | 390 × 844 | 7/7 |
| WebKit narrow | 390 × 844 | 7/7 |

Проверены локальный источник и три выходных файла; URL → пауза → продолжение → запись MDX → результат; неизвестный размер одного из двух файлов; запоздавшее событие старого запуска; ручная кодировка и выбор нескольких словарей ZIP; сохранение копии; навигация клавиатурой; длинное русское название; 70 сообщений на двух страницах; крупный текст и reduced motion. Диагностика с HTML отображается как текст.

На macOS WebKit проверка клавиатуры использует Option-Tab, на остальных конфигурациях — Tab. Это соответствует [правилам Safari](https://support.apple.com/en-gb/guide/safari/cpsh003/mac); настройки клавиатуры пользователя не менялись.

`npm run check:contracts` заново сериализует Rust DTO и сравнивает их с frontend fixtures. Typecheck и production build проходят. В production `dist` отсутствуют harness, управляющие кнопки, fixture-маркеры и тестовый URL-токен. Harness доступен только в Vite dev и не импортируется приложением.

## Визуальная проверка

Снимки показывают синтетическое состояние: скачивание завершено на 100%, запись MDX выполнена на 25%. Их значения не являются измерениями реального словаря.

Проведены один общий просмотр четырёх конфигураций и один подтверждающий. Неполная предварительная съёмка во время перезагрузки Vite была отклонена; использованы только четыре проверенных полных PNG. Найденная неточность — последняя скорость завершённого файла — покрыта сначала падающим, затем проходящим тестом и исправлена. Счётчики операций публикации не подписываются как ключи, русские числительные результата согласованы, список расширений берётся из реестра.

Горизонтального переполнения нет: ширина документа 1280/390 px. На узком экране разрешена обычная вертикальная прокрутка (869–870 px полного документа). Каждый снимок открыт и проверен: верный экран, оба блока прогресса, отсутствие пустых областей и обрезанного содержимого. Однократный `impeccable detect --json src` вернул пустой список. Финальная независимая оценка интерфейса выполняется вместе с обзором ветки.

Это тесты frontend на синтетическом bridge. Они не подтверждают работу файловых API iOS/Android, установку Windows или нативный HTTP-конвейер. Проверка настоящего macOS приложения описана в [desktop-native.md](desktop-native.md).
