# Распределение высоты 100% → 70/30

18.10.2026. Дополнение пользователя к новому рабочему окну: без завершённых проектов drag&drop занимает всё свободное место; по мере роста истории уменьшается до 30%. Убрана прежняя фиксированная высота 188px.

Верхняя область растёт по содержимому до 70% рабочей высоты. В неё входят история и строки активных задач; они сохраняют собственную прокрутку. Нижняя панель занимает остаток, минимум 30%. Без заданий пустая верхняя область не монтируется. За рабочую высоту принимается место под заголовком с учётом внешних отступов.

| Состояние | Окно | Доступная высота | Верхняя область | Панель источника |
| --- | --- | ---: | ---: | ---: |
| Пусто | 740×500 | 438px | 0px | 438px / 100% |
| Один завершённый словарь | 740×500 | 438px | 73px | 365px |
| Длинная история | 740×500 | 438px | 306,59px / 70% | 131,41px / 30% |
| История и две активные задачи | 740×500 | 438px | 306,59px / 70% | 131,41px / 30% |
| Длинная история | 540×400 | 338px | 236,59px / 70% | 101,41px / 30% |

При высоте панели до 180px уменьшаются внутренние отступы, облако и подпись остаются друг над другом. До 120px полоса скачивания имеет высоту 20px; место справа зарезервировано под паузу и отмену. Выбор файла, готовый источник и скачивание используют одну гибкую область. Цвета, иконки, порядок действий и анимация задач сохранены.

Новый тест сначала воспроизвёл ошибку: пустая панель занимала 188/438 ≈ 42,9% вместо 100%. После изменения геометрия проверяется в Chromium/WebKit и обеих темах: пусто, один/12 готовых проектов, раскрытый результат, минимальное окно, выбор файла, запуск скачивания и сочетание истории с активными задачами. Полный набор браузерных проверок — 36 сценариев, Vue — 23 теста; typecheck и форматирование проходят. Rust и нативные команды не менялись.

Один подтверждающий просмотр выполнен после сохранения вертикального расположения иконки/подписи. Однократный layout-detector вернул `[]`.

Сборка приложения и push остаются отложенными по указанию пользователя. Это проверка Vue в браузерах на macOS, не новая приёмка установленного приложения или Windows runtime.
