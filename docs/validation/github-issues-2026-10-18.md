# Сообщения о проблемах через GitHub Issues

Дата: 18.10.2026. Версия: 0.2.0. Проверки выполнены на macOS ARM64.

По последнему уточнению пользователя почтовые кнопки заменены переходом в GitHub Issues. Кнопка с оригинальной `049__mail.svg` появилась рядом с донатом и в конце строки действий каждой записи Accordion. Размер — 24×24px, иконка — 16×16px; нейтральный цвет, прозрачные фон и рамка при наведении. Подсказка и доступное имя — «Сообщить о проблеме». Состояние открытия блокирует повторное нажатие, ошибка показывается рядом с соответствующим действием и позволяет повторить.

Общая кнопка открывает форму с версией, ОС, архитектурой и полями описания, воспроизведения и ожидаемого результата. Кнопка задачи дополнительно передаёт состояние, код ошибки (включая ошибку экспорта), счётчики результата и сводку кодов первых предупреждений с числом употреблений. Сводка явно показывает число включённых групп относительно общего числа. Чтение ограничено первыми 20 группами и выполняется вне UI-потока; ошибка журнала не мешает открыть общие сведения о задаче.

URL ограничен бюджетом 7000 байт после кодирования. Имя локального файла сокращается до 60 символов; путь, query и fragment удаляются. Удалённая задача всегда называется «Словарь по ссылке»: до подготовки `display_name` может содержать hostname. Сообщения диагностики, имена статей, source locations, пути результата и исходные URL не передаются. При наличии `conversion-report.json` форма предлагает приложить его вручную после проверки содержимого. Файл не загружается автоматически.

Используются только параметры `title` и `body` фиксированной формы репозитория. Пользователь проверяет текст и публикует issue в браузере из своего аккаунта. Токена GitHub и автоматической отправки в приложении нет. Формат ссылки проверен по [документации GitHub](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-an-issue#creating-an-issue-from-a-url-query). Read-only API-проверка подтвердила, что `darkbearru/converter` публичен и Issues включены.

## Проверки

- TDD: два UI-теста сначала падали из-за отсутствия кнопок; три Rust-теста — отсутствующей функции. Отдельный regression test сначала воспроизвёл передачу hostname отменённой загрузки, затем прошёл для `source_bytes = None` и `Some(1234)`.
- `cargo test --locked -p converter-desktop --lib --offline` — 4/4. Проверены общий отчёт, контекст ошибки, отсутствие личных путей, длинные кириллические/китайские имена и большой журнал, hostname удалённого источника.
- `cargo clippy --locked -p converter-desktop --all-targets --offline -- -D warnings -A clippy::unwrap_used` и `cargo fmt --all --check` — успешно.
- `npm test -- --run` — 42/42. `npm run typecheck`, `npm run format:check`, `git diff --check` — успешно.
- Полный первый браузерный проход: 68/80; оставшиеся проверки требовали обновить ожидание четырёх действий на пять, порядок Tab и способ проверки `focus-visible` после pointer-нажатия. Повтор затронутых сценариев — 12/12 в Chromium/WebKit, обе темы.
- При просмотре снимков найден стандартный hover-фон secondary text button. Он воспроизведён отдельной CSS-проверкой и устранён повышением специфичности селектора без `!important`. Финальный проход нового сценария — 4/4: обе темы, оба движка, 740×500 и 540×400, пять действий в строке, размеры, прозрачность и клавиатурный фокус.
- Impeccable detector: новых блокирующих замечаний нет; два advisory касаются существующих 17px/18px вне изменённых правил. Sidecar дизайн-системы не обновлялся автоматически.
- Узкий независимый code review: найденный hostname case устранён и покрыт regression test.

Снимки используют синтетические данные и подмену NativeBridge, без публикации issue: [светлая тема](ui/github-issues/light.png), [минимальное окно](ui/github-issues/light-narrow.png), [тёмная тема](ui/github-issues/dark.png), [тёмное минимальное окно](ui/github-issues/dark-narrow.png).

Нативные APP/DMG в этом шаге не пересобирались; новая Windows-проверка в Actions не запускалась. Существующая история и результаты пользователя не изменялись. Проверка реальной отправки issue не проводилась, публикаций и новых коммитов не создавалось.
