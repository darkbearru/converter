# Локализация RU/EN — 2026-10-19

Реализация выполнена в локальной ветке `codex/localization`. Отправка изменений, GitHub Actions, выпуск релиза и публикация Pages не выполнялись по указанию пользователя.

## Поведение

- Основной язык ОС `ru` выбирает русский; `en`, неподдерживаемый и неизвестный — английский. Вторичные языки не влияют на выбор. На macOS `sys-locale` использует список предпочитаемых языков системы, на Windows — UI language API.
- В «О программе» доступен выбор «Системный / System», «Русский», «English». Он сохраняется атомарно в `app_config_dir/preferences.json`. Повреждённый файл сохраняется отдельно перед заменой; отказ записи не меняет подтверждённый язык.
- Язык переключает собственные тексты Vue/PrimeVue, нативные заголовки и меню About, новые ошибки/предупреждения и форму GitHub Issues. Содержимое словарей не переводится.
- Общая конфигурация `config/locales.json` задаёт ссылки поддержки. В RU сохранён CloudTips, в EN элементы поддержки скрыты до настройки URL.
- Сайт подготовлен на `/ru/` и `/en/`. Корень выбирает основной язык браузера с английским fallback; ручной выбор сайта запоминается отдельно от приложения. Без JavaScript доступна полная английская страница. Существующий workflow продолжает брать версию и оба установщика из одного стабильного релиза.

Локальный просмотр сайта использовал фиксированный релиз 0.2.6; это проверка шаблона, не опубликованный новый релиз.

## Решения после проверки кода

- Общие helper-функции ошибок DSL/валидатора MDX/MDD получили явные ключи; преобразование ошибки сохраняет параметры и исходную позицию. Регрессионные тесты сначала подтвердили потерю метаданных, затем прошли после исправления.
- Смена locale PrimeVue сохраняет defaults и aria-объявления выбора. Проверено отдельным тестом; предупреждение ревью оценено как существенное для доступности и исправлено до сборки.
- Дополнительный тест компилирует каждый текст Vue I18n: он выявил литерал `@`, исправленный на `{'@'}`.
- Увеличение размера ошибки из-за метаданных проявило переполнение стека в прежнем тесте глубины 128. Чистый baseline прошёл; внутренний рекурсивный Renderer теперь возвращает boxed-ошибки. Публичный Result и JSON-контракты не изменены, настройки стека и лимит глубины не увеличивались. Метаданные также хранятся в Box для компактного размера значения ошибки.
- Два прерванных браузерных сценария совпали с перезагрузкой Vite. Повтор этих сценариев и полный прогон без параллельного изменения файлов прошли; обходы фокуса и увеличение таймаутов не добавлялись.

## Границы проверки

Старые журналы без `message_key`/`message_args` продолжают показывать исходные сообщения, включая русские тексты. Они не переписываются и не перегруппировываются при смене языка.

Основной язык ОС проверен инъекцией локалей и нативными unit-тестами; язык текущей macOS вручную не менялся. Проверки интерфейса выполнены через браузерный harness и production assets с CSP, не через автоматизацию нативного окна. Системные стандартные пункты меню и кнопки файловых диалогов остаются под управлением ОС. Нативная визуальная приёмка готовой macOS-сборки передаётся пользователю.

Windows не запускалась в этой итерации. Проверка Windows x64 через существующий GitHub Actions и публичная проверка Pages отложены до разрешения на push/публикацию. Intel macOS и мобильные платформы не собирались.
