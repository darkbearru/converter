# Нативные проверки desktop

Дата: 2026-10-18. Платформа: macOS ARM64. Используются собственные синтетические DSL и ресурсы; пользовательский словарь не предоставлен.

## Tauri debug app, C3

`npm run tauri -- dev` собрал и запустил небандлированный процесс. Инструмент управления окнами не распознаёт такой процесс, поэтому дальнейшая проверка выполнена в настоящем `.app`, созданном командой `npm run tauri -- build --debug --bundles app`.

- Локальный `acceptance.zip` выбран системным файловым диалогом. Отмена диалога назначения сохраняет предыдущий выбор.
- Выбрана папка `.work/native-smoke/Результаты`. Получены 3 статьи, 6 ключей, 4 ресурса; MDX, MDD, `conversion-report.json`. Единственное предупреждение unknown_tag соответствует fixture: неизвестный тег сохранён как текст.
- «Открыть папку результата» открыл Finder с тремя ожидаемыми файлами в выбранной папке. Путь передаётся opener из Rust по ID задания.
- Для URL использован `native_smoke_server` из dev-only `converter-test-support`: ZIP 7 860 847 байт, 60 002 статьи, PNG и WAV. Первый HTTP-ответ оборван после 1 048 576 байт; последующий ответ удерживается до команды `release`.
- На паузе видны отдельные блоки: скачивание 1 МиБ из 7,5 МиБ (13%), конвертация не началась. Cmd-Q завершил процесс штатно.
- После открытия `.app` восстановились 1 048 576 подтверждённых байт и пауза. «Продолжить скачивание» отправил `Range: bytes=1048576-`, `If-Range: "fixture-v1"`.
- После `release` получен результат: 60 002 статьи, 60 002 ключа, 3 ресурса (включая CSS), скачивание 100%, конвертация завершена.
- Повторная конвертация того же задания завершилась с generation 3 и папкой `Нативный тест-converted`. Число GET осталось 3: начальный запрос, диапазон до паузы, диапазон после открытия. При повторной конвертации новых GET нет.
- Нативная accessibility-проверка выявила отсутствие численного значения у завершённой конвертации. Регрессионный тест сначала упал; исправление задаёт 100 при `succeeded`. Обновлённый `.app` показал accessibility-значение 100.

Синтетический ZIP создаётся средствами разработки; приложение не запускает Python/PHP и не включает их в дистрибутив. Все операции конвертации и HTTP выполняет Rust.

## Release-пакеты, C5

`Desktop packages` [39111278658](https://github.com/darkbearru/converter/actions/runs/39111278658), commit `052d234`, успешно собрал macOS ARM64, macOS Intel и Windows x64 NSIS. Перед Windows-упаковкой прошли отдельные writer conformance, checkpoint recovery и desktop publication tests. Каждый архив содержит build-info с commit, версиями, хешами lock-файлов и SHA-256 артефактов. Сборки не подписаны сертификатом разработчика и не notarized.

Локально проверен release `.app` из `00067e0`:

- Повторная конвертация завершённого URL-задания работает при остановленном HTTP-сервере: используется проверенный локальный источник.
- Реальный обрыв после 1 МиБ, отмена, повтор, пауза, Cmd-Q, открытие и докачка проверены через интерфейс. После открытия сохраняются 1 МиБ/13%, запрос содержит `Range: bytes=1048576-` и `If-Range: "fixture-v1"`. После разрешения ответа — 60 002 статьи, 60 002 ключа, 3 ресурса, оба прогресса 100%.
- Отмена немедленно отображается и у задания, и у файла; подтверждённый префикс остаётся. Старое некорректное сохранённое состояние Cancelled/Downloading нормализуется при открытии. Обе ошибки сначала воспроизведены регрессионными тестами; app suite 18/18.
- Результат release-конвертации из папки `Нативный тест-converted-2` открыт в GoldenDict-ng 26.8.0: статья `alpha`, изображение из MDD, ссылка `tone.wav` вызывает обработчик Audio. Акустическое воспроизведение не измерялось. Официальный DMG ридера проверен по SHA-256 `2369c5bba5c68cd42061be8482813199c3fbe04e895616b62c4c3d5e7e233757` и смонтирован только для этой проверки.

Выбранный пользователем корневой `book.svg` подключён к заголовку и desktop-иконкам в `5908a86`. Его актуальные снимки проверены в Chromium/WebKit на 1280×800 и 390×844; переполнения по горизонтали нет. Происхождение PNG встроено в сами файлы и описано в `src-tauri/icons/ORIGIN.md`.

## Границы подтверждённого покрытия

Это проверка реального Tauri/WebKit приложения на macOS. Intel-пакет собран на Intel runner, но интерактивно не запускался. NSIS успешно установлен в кириллическую папку GitHub Windows runner с уже установленным WebView2; нативный WebDriver-сценарий проверяется отдельным workflow `windows-native.yml`. Браузерный harness не является нативной проверкой.

Отдельная чистая Windows VM без WebView2 и сети в этой среде недоступна. Поэтому установка встроенного offline runtime, ручные Windows file-picker/export и открытие словаря в Windows-ридере остаются непроверенными. Протокол такой проверки приведён в `docs/build/windows.md`; наличие `offlineInstaller` не считается её выполнением. Подпись, notarization, iOS/Android и акустическое измерение воспроизведения не выполнялись.
