# Приёмка ядра и CLI

18 октября 2026 года, macOS ARM64, Rust 1.99.1. `cargo test --locked -p converter-core -p converter-cli`, fmt и Clippy с `-D warnings` прошли. Состав проверок включает независимое чтение MDX/MDD, все кодировки, ограниченную сортировку, checksum, ссылки, ресурсы, отмену и публикацию без замены файлов. Миллионный тест прошёл локально и на macOS/Windows в CI; [отдельный протокол](pipeline-2026-10-18.md).

CLI преобразовал контрольный ZIP из `generate_acceptance_fixture`: три исходные статьи, шесть ключей, четыре ресурса вместе с CSS, одно ожидаемое предупреждение `unknown_tag`. Созданы MDX/MDD и JSON-отчёт в `.work/reader-acceptance/output/main-converted`. Повторная конвертация сохраняет оба результата; автоматический тест также сохраняет существующие пустую папку и файл с занятыми именами.

Нативный Ctrl-C проверен отдельно на DSL из 100 000 статей (11 388 955 байт): процесс завершился с кодом 130 и диагностикой `cancelled`, папка вывода осталась пустой. Временные файлы незавершённой конвертации удалены.

Независимое графическое приложение: [GoldenDict-ng 26.8.0, Qt 6.10.3, macOS ARM64](https://github.com/xiaoyifang/goldendict-ng/releases/tag/v26.8.0). Официальный DMG использован временно, без копирования приложения в `/Applications`. SHA-256 DMG совпал с опубликованным release digest: `2369c5bba5c68cd42061be8482813199c3fbe04e895616b62c4c3d5e7e233757`.

Звук проверен до обработки ссылки нативным ридером; акустический выход и фактическая слышимость не измерялись. Это ограничение наблюдения, а не доказательство успешного воспроизведения на конкретных колонках. Автоматические тесты отдельно проверяют полное извлечение байтов ресурсов и SHA-256.

Проверка выполнена на созданном контрольном словаре. Реальный словарь пользователя пока не передан. Продуктовая оболочка и URL-загрузка относятся к следующим этапам B/C; наличие CLI не означает их готовность.
