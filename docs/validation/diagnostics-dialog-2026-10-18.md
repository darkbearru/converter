# Полный журнал предупреждений — 18.10.2026

Пользователь уточнил: «(ещё N предупреждений)» в истории должна быть ссылкой с пунктирным подчёркиванием, открывающей отдельный Dialog со всем списком. Для URL подтверждены только архив либо один словарь; поиска соседей у одиночного URL нет. Последнее правило отражено в [схеме расширения ядра](../analysis/chinese-package-2026-10-18.md), автоматический поиск и объединение баз по-прежнему не реализованы.

В истории сохраняется одно сообщение. Счётчик — настоящий `a` с `href`, `aria-controls` и `aria-haspopup="dialog"`; обработчик открывает PrimeVue Dialog без навигации. В окне видны имя словаря, сообщения и места в исходнике. Чтение идёт страницами по 50 через существующий `readDiagnostics`; PrimeVue Paginator позволяет переходить вперёд/назад и сразу к первой/последней странице. Полный список доступен, одновременно в DOM не более 50 записей. Закрытие крестиком, нижней кнопкой и Escape возвращает фокус к ссылке. В WebKit явный фокус перед открытием учитывает различие между кликом мышью и Enter.

Загрузка имеет статус, ошибка — сообщение и повтор чтения. Устаревшие ответы защищены счётчиком поколений. Обычный журнал активного задания сохраняет прежнее раскрытие и страницы по 50. Пагинатор наследует Aura, без попадания под старые общие стили ручных кнопок. Палитра, серый ряд действий, красное удаление, 24px/gap12 и расположение 100% /70–30% сохранены.
