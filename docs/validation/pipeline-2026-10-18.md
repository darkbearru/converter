# Дисковая конвертация и нагрузочная проверка

Ядро хранит HTML на диске один раз на исходную статью. Сортировочные строки содержат ключ, порядковый номер и диапазон HTML; дубли сохраняют исходный порядок. Отсортированные run-файлы объединяются с конечным fan-in. Список всех run-файлов не накапливается в памяти: используются номера прохода и файла.

SQLite с включённым bundled-режимом хранит индекс ключей/ссылок на диске с кэшем страниц 1 MiB. Установка отдельного SQLite не нужна. Сортировку выполняет собственное объединение run-файлов. Диагностика и итоговый JSON-отчёт пишутся потоково. Штатная проверка MDict читает все блоки с проверкой Adler-32, геометрии и счётчиков; тесты дополнительно используют независимый mdictlib.

Малый интеграционный тест: 300 исходных статей, 600 ключей, буфер 4096 байт, fan-in 2. Проверены несколько проходов, порядок 300 дубликатов, отсутствующая ссылка, MDD-ресурс 1 228 800 байт, CSS внутри MDD, повреждённый checksum и отмена с очисткой staging. Отдельный тест проверяет ссылку на подстатью с несортируемой и необязательной частями. SQL-проверка ссылок прерывается через SQLite progress callback; регрессия воспроизводится на 500 000 существующих ссылок.

Крупный прогон 18 октября 2026 года на macOS ARM64 выполнен командой:

```sh
cargo test --locked -p converter-core --test large_dictionary -- --ignored --nocapture
```

RSS измеряется sysinfo по resident size собственного процесса каждые 100 мс. Это максимум выборки, а не гарантированный пик между измерениями. Бюджет строк сортировки учитывает ёмкость таблицы строк и строковые буферы; RSS дополнительно включает аллокатор, SQLite, IO, декодер и писатель. Независимый ридер успешно нашёл первый и последний ключи. Файлы теста создаются во временном каталоге и удаляются после проверки.

Обычный CI выполняет быстрые тесты на macOS/Windows. Для отдельного release-прогона крупного теста workflow_dispatch поддерживает `large_dictionary=true`; цифры разных ОС и профилей следует сравнивать отдельно.

[Нагрузочный CI](https://github.com/darkbearru/converter/actions/runs/39105500271) на коммите `06d2a4d` завершился успешно на обеих ОС. Это отдельные release-сборки на GitHub-hosted машинах, не прямое сравнение с локальным debug-прогоном:
