# Компактные предупреждения и кнопки — 18.10.2026

По последнему уточнению пользователя кнопки ссылки и настроек имеют область иконки 24×24px, без рамки/фоновой плашки; промежуток 12px. Размер принадлежит локальной переменной `--tool-size` на `.composer-tools`, остальные иконки приложения не менялись. Сохранены подсказки, disabled, hover и клавиатурный focus-visible.

Раскрытая история загружает и показывает только одно предупреждение и его источник. При наличии остальных рядом выводится «(ещё N предупреждений)» с русским склонением. Кнопка «Показать все» убрана из истории. Полный JSON-отчёт сохраняется; отдельный диагностический компонент в подробностях активного задания сохраняет постраничное чтение.

Регрессионные проверки сначала воспроизвели прежний промежуток 0px и отсутствие краткого счётчика. После правок Vue28/28, полный Playwright40/40 (Chromium/WebKit, светлая/тёмная тема), typecheck проходят. Браузер проверяет реальные размеры 24×24, gap12, border0 и одну запись при 70 предупреждениях. Rust не менялся; предыдущий полный workspace79pass/1ignored остаётся проверкой того же ядра.

Финальные снимки: [пустое окно](ui/compact-warning/empty-dark.png), [предупреждение](ui/compact-warning/warning-dark.png), [540×400](ui/compact-warning/warning-small-light.png), [измерения](ui/compact-warning/measurements.json). Три синтетических состояния, ошибок JS нет, происхождение PNG записано. Первый захват с незавершённым поворотом chevron заменён статичными снимками с reduced motion; это настройка проверки, анимация продукта не менялась. Detector сообщил только существовавшие ранее рекомендации по 17px/18px.

Отдельное исследование пользовательского ZIP и предлагаемая обработка связанных баз описаны в [разборе архива](../analysis/chinese-package-2026-10-18.md). Автоматического объединения баз и изменения разбора тегов эти UI-правки не добавляют.
