# Поле ссылки, прогресс и поддержка разработчика — 18.10.2026

Пункты 1–4 пользовательского запроса реализованы в прежнем интерфейсе PrimeVue. Процент скачивания округляется до целого в ProgressBar; неизвестный размер остаётся неопределённым. Поле SHA-256 убрано из текущего Dialog; контракт источника и проверки контрольных сумм в Rust сохранены, новые ссылки передают `expected_sha256: null`.

Предоставленный `paste_icon.svg` помещён справа внутри поля URL. Нажатие читает текст через Rust-команду и официальный `tauri-plugin-clipboard-manager`, без зависимости от Clipboard API WebKit. Текст вставляется без краевых пробелов; скачивание требует отдельного нажатия. При пустом/недоступном буфере остаётся прежний URL и появляется сообщение. Запоздавший ответ после закрытия Dialog или правки URL не перезаписывает поле.

После подписи форматов добавлена кнопка «Поддержать разработчика»: 24×24px, `126__cash.svg` — 16×16px. Команда `open_support_page` не принимает URL и открывает только `https://pay.cloudtips.ru/p/7e782291` через существующий нативный opener. Обе кнопки имеют подписи, прозрачные поверхности и клавиатурный фокус Aura. SVG предоставлены пользователем; для paste применяется contain вместо увеличенной маски набора svg-single.
