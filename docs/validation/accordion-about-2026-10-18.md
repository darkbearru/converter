# Отступ, полный журнал и благодарность — 18.10.2026

В версии 0.2.0 верхний отступ содержимого Accordion увеличен с 2 до 8px. Предпросмотр предупреждения остаётся PrimeVue Message, а полный журнал снова показывает обычные текстовые строки с прежними разделителями. Число употреблений, координаты и пагинация сохранены.

Для стандартного macOS About подготовлен Credits.rtfd с копирайтом, активной ссылкой «Сказать спасибо» и изображением из исходного `126__cash.svg`, окрашенным #F96133. Далее остаётся darkbear.ru. Иконка 16×16pt хранится как PNG 32×32px с DPI 144; и изображение, и текст входят в один диапазон ссылки `https://pay.cloudtips.ru/p/7e782291`. Ресурс содержит одну картинку и две ссылки, внешние ресурсы не загружаются.

AppKit поддерживает Credits.rtfd как штатный ресурс [Credits](https://developer.apple.com/documentation/appkit/nsapplication/aboutpaneloptionkey/credits?language=objc). Отдельный нижний копирайт стандартного окна скрыт только для macOS через Info.macos.plist, чтобы показать единственный копирайт перед ссылкой благодарности. Общие метаданные copyright в конфигурации сохранены для других платформ. Изменений Rust-кода и ядра нет.

Начальная нативная проверка выявила стандартный обратный порядок Credits/копирайта, который исправлен одной подтверждающей сборкой. About оставлено открытым для пользователя.
