# Уточнение About и GitHub Issues — 18.10.2026

Причина прежнего смещения: bounds.origin.y у NSTextAttachment не сохраняется в RTFD. Для самой картинки задан baselineOffset −4pt, который после повторного чтения AppKit присутствует как −4.0; текст ссылки имеет обычную базовую линию. Изменений Vue/Rust, новой формы bug-report и публикации GitHub в этой задаче нет.
