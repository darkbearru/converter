# ZIP с паролем, составные DSL и уточнения интерфейса

Локальная ветка `codex/localization`, исходный коммит реализации `de631d7`. Публикация релиза, Pages, push и Windows CI не выполнялись.

## Изменения

- ZIP с ZipCrypto и AES-128/256 запрашивает пароль на этапе подготовки. Диалог поддерживает повторный ввод; отмена оставляет задание ожидающим, «Уточнить параметры» открывает ввод снова. Повторное открытие не сохраняет введённое поле. Скачанный ZIP повторно используется из кэша. Пароли хранятся только в runtime, отдельно от сериализуемых заданий, отчётов и настроек; после завершения удаляются из runtime.
- `#INCLUDE` объединяет локальные части рядом с исходным DSL либо части внутри того же ZIP. Вложенные включения поддерживаются, каждая часть читается один раз, включённые части не предлагаются отдельно. Метаданные берутся из главного словаря, позиции предупреждений сохраняют имя и строку фактической части. Отсутствие файла, цикл, выход за пределы папки, symlink и превышение лимитов сообщаются явно.
- Отступ `[mN]` завершается следующим абзацем или концом статьи; повторный `[/m]` допускается как сброс отступа. Повреждённые ссылки и другие структурные ошибки остаются проверяемыми. Текст не отбрасывается для обхода ошибки.
- Отображение обычных drive/UNC-путей Windows скрывает `\\?\`; канонические пути и проверки разрешённого назначения не менялись. Пользователь уточнил, что причиной отказа была ошибка DSL `[m]`, а не подтверждённый отказ файловой системы.
- Подпись «Язык»/`Language` и вариант «Системный»/`System` используют текущий язык интерфейса. Названия «Русский» и `English` остаются собственными названиями языков.
- Английская ссылка поддержки приложения и сайта — `https://hipolink.net/darkbear_ru/tips`; русская CloudTips сохранена. Английский снимок сайта обновлён из реального Vue harness.

## Реальный словарь и сравнение с Python

Источник: предоставленная папка `dsl_dabkrs_260610`, основной `dabkrs_1.dsl`, включения `dabkrs_2.dsl` и `dabkrs_3.dsl`. Все три исходных файла читаются без изменения.

До исправления реальный прогон останавливался с `invalid_markup` на строке 14797 основного файла: абзац `[m2]` не имел явного закрытия перед `[m1]`. После исправления конвертация всех частей завершилась и прошла полную встроенную проверку MDX/MDD.

| Проверка | Статей | Ключей / записей | Результат |
|---|---:|---:|---|
| Converter, окончательный код | 3 452 947 | 3 452 947 | MDX + MDD, проверка блоков/сумм/счётчиков пройдена |
| Реальный Python DSL reader → MTXT | 3 452 947 | 3 452 947 | успешно, пустые трансформации и ошибки преобразования не зарегистрированы |

Python использовал тот же неизменённый [Pyglossary fork](https://github.com/sobaee/pyglossaryfork/tree/a7bb34b00b16be23f75f8d9a13362d70ee1a66b2), на котором основан [dict2mdx](https://github.com/sobaee/dict2mdx). Локальный наблюдательный wrapper считал вызовы и записи без изменения reader/transformer/writer. Сравнивался реальный этап DSL → MTXT, не полная упаковка Python в MDX. Совпадение счётчиков не заявляется как побайтовое равенство HTML двух разных конвертеров.

В Converter осталось **159 предупреждений `missing_reference`**: 53 в первой части, 56 во второй, 50 в третьей. Они не блокируют выдачу результата. Отсутствующие расшифровки помет и восстановленные пересечения оформления учитываются как информационные сообщения.

Результат окончательного прогона: `.work/dabkrs-final/dabkrs_1-converted/`. Содержимое MDX/MDD побайтово совпало с первым успешным прогоном; последующее уточнение исходных позиций изменило только отчёт.

Подготовка и чтение используют одинаковую политику автоопределения кодировки каждой части с ручным fallback. Все три новые проверки прошли после исправления; повторное ревью не запускалось.

Первый полный запуск браузеров был остановлен из-за зависшего тестового Vite (не отвечал даже `@vite/client`); перезапуск восстановил работу. В следующем прогоне 104 сценария прошли, четыре остановились на опечатке matcher в новом тесте. После её исправления полный прогон дал 108/108 без изменения таймаутов и обхода проверок.

Границы: нативная Windows в этой итерации не запускалась; её пути проверены строковыми тестами, файловая логика канонизации сохранена. Визуальная проверка — Vue harness и снимки из [ui/source-fixes-2026-10-19](ui/source-fixes-2026-10-19). Нативная приёмка macOS передаётся пользователю.
