# Рабочее окно Converter 740×500

Дальнейшее изменение высоты панели до 100% свободного места и предела 70/30 описано в [дополнении](composer-layout-2026-10-18.md). Размер 188px в этом первоначальном протоколе относится к предыдущей версии интерфейса.

18.10.2026. Переработка по image1–image5 пользователя: история в PrimeVue Accordion сверху, FileUpload-панель снизу, активные задачи между ними. Vue-компоненты Dialog и ProgressBar, Aura с системной темой, #F96133 для действия/конвертации и #65C8EE для скачивания. SVG предоставлены пользователем; рисунок книги увеличен на 30% с сохранением прозрачных полей. В конфигурации Tauri задано изменяемое окно 740×500, минимум 540×400.

По ссылке сначала скачиваются словарь и указанные ресурсы. Состояние Ready сохраняется при перезапуске; конвертация начинается отдельной кнопкой. Скачивание имеет паузу/докачку и отмену; конвертация — отмену/повтор. После запуска нижняя панель свободна для следующего источника. Новые строки появляются из-под неё; при большом числе задач стопка прокручивается к новой строке. Reduced motion убирает перемещения.

## Проверки

- Rust: полный workspace — 75 пройденных и 1 пропущенный большой нагрузочный тест до исправлений ревью; после исправлений повторно весь изменённый converter-app — 24/24. Всего в workspace теперь 76 обычных тестов. Большой отдельный тест из прежнего протокола не повторялся для этой UI-правки.
- `cargo clippy --workspace --all-targets --locked -- -D warnings` — успешно, включая Tauri-команды и обработчик drop.
- Vue/Vitest — 23/23; проверены явный запуск, URL-подготовка, native-drop metadata, восстановленные ресурсы, закрытие диалога во время сохранения, обновление пути результата и поздняя ошибка старого запроса.
- Playwright — 32/32:8 сценариев × Chromium/WebKit × светлая/тёмная тема. Viewport740×500, уменьшение 540×400, клавиатура, длинные имена,70 диагностик постранично,5 активных задач, reduced motion, pause/resume, неизвестный размер, сбой скачивания ресурсов, ZIP-выбор, запоздавшие события, сохранение копии.
- `npm run typecheck`, `npm run check:contracts`, `npm run format:check`, `git diff --check` — успешно. Rust DTO и frontend fixtures сериализуются одинаково.

Дефекты независимого code review исправлены: прежние ресурсы восстановленного Ready-задания сохраняются при добавлении новых; ID удерживаемых ресурсов проверяются на принадлежность заданию, дубликаты исключаются, пустой список удаляет всё. Публичные snapshot содержат только ID/имена/размеры ресурсов. Закрытие диалога не прерывает уже отправленную команду сохранения/запуска. Запоздавшая ошибка старого пути не отменяет новый запрос.

## Область подтверждения

Новая сборка приложения, установка и push не выполнялись по указанию пользователя. Изменённые команды Tauri проверены компилятором; работа нового drop-обработчика, OS opener, размеров нативного окна и увеличенной иконки в установленном приложении требует следующей разрешённой сборки. Chromium/WebKit запущены на macOS; это не новая проверка Windows/WebView2. Мобильные SDK и сборки отложены. Прежние нативные протоколы описывают прежнюю сборку и не подтверждают этот новый UI.

Независимое визуальное ревью подтвердило компоновку и назначило одно исправление: контраст текста кнопок светлой темы. Тест сначала воспроизвёл 3,0948:1 вместо 4,5:1. Исправлен токен primary.contrastColor; подписи контурных/текстовых кнопок светлой темы используют primary700, заливка основного действия остаётся #F96133. Финальный прогон 32/32 включает вычисление контраста подписей в обеих темах. Все 15 состояний пересняты по прежним путям. Вердикт исправления — **ship**, замечание **resolved**: 6,43:1 для заполненной кнопки и 6,00:1 для контурной. Это оценка перечисленного исправления, не приёмка нативного приложения. Система оформления описана в [DESIGN.md](../../DESIGN.md).
