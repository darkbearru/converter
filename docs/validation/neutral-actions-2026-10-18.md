## Узкая проверка приложения macOS

Собран APP с окончательным кодом: `target/aarch64-apple-darwin/release/bundle/macos/Converter.app` (19,56 MiB). Предыдущий принадлежащий этой проверке простаивающий процесс завершён; перед запуском нового экземпляра `pgrep` подтвердил его отсутствие. Запущен именно новый APP. Свежие Accessibility-данные содержат «Открыть папку», «Сохранить копию», «Повторить», «Удалить»; нативный снимок 740×500 подтверждает первые три серыми, удаление красным и один ряд кнопок. Пользовательские данные сохранены. Приложение оставлено открытым на выбранном пользователем раскрытом результате `main.dsl`.

Эта проверка подтверждает обновлённый ряд действий в приложении macOS. DMG/ZIP не обновлялись; широкая нативная приёмка C5 и Windows не заявляется.
