# Chinese.zip: основной словарь и независимые базы

Статус: исследование дополнено реализованным поведением от 18.10.2026. Последнее указание пользователя: автоматически конвертировать основной, спросить о несвязанных словарях и при согласии запускать их отдельными обычными заданиями. Раннее предложение объединять PhoneticList и Universal **заменено этим решением и не является текущим режимом по умолчанию**. Поиск соседних баз в исходной локальной папке остаётся будущей работой.

## Реализованный запуск и согласие

Основной конвейер продолжается сразу после анализа и не ждёт Dialog. «Другие словари в архиве» показывает имя основного и независимые базы. «Конвертировать» создаёт по отдельному обычному заданию на каждую из них: собственный UUID, прогресс, отчёт, MDX/MDD и повтор. Существующая очередь обрабатывает задания последовательно. В этом архиве получаются Universal и, после согласия, PhraseBook; PhoneticList к результату не добавляется.

«Пропустить», обычное закрытие и Escape сохраняют отказ. Во время сохранения действия, крестик и Escape заблокированы. Согласие и заранее выделенные ID сохраняются; повтор той же команды возвращает прежние задания. Прерванный принятый план восстанавливается при старте без повторного создания уже обработанных, в том числе позднее удалённых, заданий. Кодировка, ресурсы и папка наследуются; название/описание берутся из собственной базы, без переноса переопределённого названия основного.

Если сохранить решение не удалось, окно хранит своё предложение даже после события родительского задания и позволяет повторить. «Закрыть» после ошибки лишь скрывает окно в текущем сеансе и оставляет основной доступным; второе решение не отправляется. Несохранённое предложение может появиться при следующем запуске; уже принятый план восстанавливается.

Объединение статей/ресурсов нескольких баз не выполняется. Анализ графа для выбора основного не является общей реализацией переносимых межсловарных переходов.

Выбор основного и план дополнительных заданий сохраняют SHA-256 выбранного файла словаря внутри архива. Повторное извлечение перед конвертацией/повтором проверяет содержимое: перепакованный архив не может подменить выбранную базу по порядковому ID. При несовпадении задание получает `source_changed` с предложением выбрать архив заново.

## Совместимый разбор оформления

Первая диагностическая проба старого ядра завершалась `invalid_markup` на Universal и PhraseBook при пересекающихся тегах оформления. Это исторический результат, **не текущее ограничение**.

Текущий парсер нормализует такое оформление в корректный HTML, сохраняя текст и атрибуты. Восстановление получает `repaired_markup` с местом в источнике. Сокращения, ref/url, ресурсы и блоковые границы сохраняют семантику и не разбиваются восстановлением. Поддержаны стандартные зоны ударения и необязательных примеров. Неизвестные теги сохраняются текстом с предупреждением; настоящие ошибки структуры/разметки и кодировки, ограничения размера/глубины и отмена остаются контролируемыми.

## Границы источников и будущий поиск соседей

Пользователь подтвердил: внешний словарь может находиться рядом с одиночным DSL. Только чтение имён/заголовков в исходной папке подтвердило наличие Universal, его `_abrv` и PhraseBook рядом с выбранным PhoneticList. Автоматического поиска в этой папке **нет**. `PlatformStorage::import` сохраняет канонический путь, что позволяет рассмотреть его в отдельной будущей работе.

Исследовательские правила будущего поиска: ограничиться исходной папкой без подпапок и переходов по символьным ссылкам; сопоставлять `dict` с #NAME; отличать отсутствие базы от недоступности/ошибки кодировки; выявлять одинаковые названия; не подключать несвязанные соседние словари. Эти правила не описывают текущий продукт и не определяют способ упаковки результата.

Для URL остаются два варианта: архив либо один словарь. Анализ архива ограничен его содержимым. Одиночный локальный или URL-источник не запускает поиск соседей; загрузочный кэш не сканируется, соседние URL не угадываются.

## Исторические результаты исследования

В PhoneticList найдены 28 173 явные ссылки на Universal. Первое сравнение исходных заголовков находило 28 148 целей, после штатного раскрытия вариантов и нормализации — 28 149; 24 ссылки оставались без точного ключа. Это число ссылок, не уникальных статей. Диагностический разбор PhoneticList дал 22 949 статей и 22 943 уникальных нормализованных ключа. В той версии renderer терял атрибут dict, после чего проверка ссылок искала адресата в текущем результате. Эти числа относятся к исследованию прежнего поведения; текущий автоматический запуск не конвертирует указатель и не обещает исправления всех его ссылок.

Ранняя исследовательская схема предлагала общий переносимый MDX/MDD для связанных баз, сохранение происхождения при совпадении ключей и разнесение ресурсов по источникам. Она требовала отдельной проверки переходов в нескольких читалках. **Схема объединения отменена последним уточнением пользователя для этой доработки:** сейчас основной конвертируется отдельно, независимые — только по согласию. Объединение, разрешение коллизий нескольких баз и межсловарные переходы не заявляются реализованными.
