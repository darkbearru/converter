# Страница загрузки Converter

Режим: Persuade. Публичная страница GitHub Pages для пользователя словарей; действие — скачать установщик для своей платформы. Пользователь поручил сразу сделать и опубликовать страницу, оставив последующие правки себе. Визуальные макеты и дополнительное согласование не требуются.

## Direction contract

THESIS: кратко объяснить преобразование DSL в MDX/MDD и сразу дать два установщика. Никакой выдачи служебных файлов релиза.

OWN-WORLD: наследуем книгу Converter, оранжевый #F96133, голубой #65C8EE и простой шрифт приложения. Белая страница читается как описание настольной утилиты в обычном дневном освещении; контрастный заголовок и тёмный снимок интерфейса связывают её с продуктом.

STORY: посетитель узнаёт формат результата и локальный способ работы, выбирает macOS Apple Silicon или Windows x64 и скачивает файл без входа в GitHub.

FIRST VIEWPORT: логотип и ссылка на исходники сверху; слева заголовок, описание и две кнопки, справа настоящий интерфейс с синтетическим словарём. На телефоне кнопки остаются перед снимком. Ниже — три коротких объяснения возможностей и ссылки помощи.

FORM: узкая страница по конкретному заданию пользователя, без выбора нового визуального мира; concept-seed не нужен. Номер версии и ссылки внедряются при сборке из последнего стабильного релиза.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Уточнения от 19.10.2026

По правкам владельца ссылка «Сказать спасибо» с оранжевой `126__cash.svg` находится в шапке и первой в подвале. Заголовок использует основной `--accent`; подписи установщиков белые. Для контраста небольших надписей используется оттенок `--accent-readable` (#C6411C): заливка кнопок и текст ссылок поддержки, контраст с белым 5,03:1. Наведение затемняет заливку через `color-mix()`. На экранах до 480px логотип занимает первую строку, две ссылки — следующую. Сборка включает новую иконку; декоративные картинки не дублируют доступное имя ссылки.

Проверены 1280×720, 390×844 и 320×844: все изображения загружаются, переполнения нет, обе кнопки скачивания видны в первом экране. Локальные снимки и измерения: `.work/pages-review/validation/`. Проверка сборки контролирует доступность всех локальных изображений и стилей итоговой страницы. Механизм получения версии и установщиков из стабильного релиза сохранён.

Независимое finish-review: ship, блокирующих и важных замечаний нет. Проверки: 3 теста сайта, 45 тестов приложения, форматирование и diff-check пройдены.
