# Автоматический основной словарь и дополнительные базы

Условия уточнены пользователем 18.10.2026: в `chinese.zip` автоматически конвертируется только основной Universal. Для независимого PhraseBook приложение предлагает отдельный запуск. PhoneticList служит указателем на Universal и автоматически не конвертируется. Объединение баз в этой доработке не выполняется.

## Поведение

После подготовки архива читатели анализируют `#NAME` и явные межсловарные ссылки. Для DSL исключаются комментарии, экранированные теги и `_abrv`. Основной определяется по графу: единственный конечный адресат ссылок, без циклов и неоднозначных названий. Неизвестный формат анализа, нечитаемая база, отсутствующий адресат, несколько основных или отсутствие связей сохраняют существующий ручной выбор. Ручной ранее сохранённый выбор имеет приоритет. Сокращения и ресурсы подключаются существующим способом.

Основной запускается сразу после анализа. Найденные изолированные базы показываются в Dialog «Другие словари в архиве»: список файлов, «Пропустить» и «Конвертировать». Отказ и закрытие означают сохранённый отказ. Согласие создаёт по отдельному обычному заданию на каждый независимый словарь, с собственными ID, прогрессом, отчётом, результатом и повтором. Существующая очередь обрабатывает их по одному; отдельные процессы ОС не нужны. Окно не останавливает основной конвейер.

Предложение доступно и после завершения основного. Решение и заранее выделенные ID дочерних заданий сохраняются. Повтор команды идемпотентен. Принятое решение, прерванное между записями файлов очереди, восстанавливается при старте; уже запущенные или позднее удалённые задания повторно не создаются. Дочерние задания наследуют кодировку, ресурсы и папку; название/описание берутся из собственной базы, без копирования переопределённого названия основного.

Для одиночного локального/URL-источника этот анализ не ищет соседей. URL остаётся архивом либо одним словарём. Предложенный раньше поиск по исходной папке и объединение связанных баз остаются отдельной будущей работой.

Автоматический основной и предложенные дочерние базы привязаны к SHA-256 выбранного члена архива. Перед конвертацией и повтором содержимое сверяется: изменение порядка файлов не должно незаметно подменять словарь. Несовпадение даёт `source_changed` с просьбой выбрать архив заново. Анализ ссылок использует те же границы `<<…>>`, включая экранированные разделители, что и renderer; текст внутри такой ссылки не создаёт межсловарную зависимость.

При ошибке сохранения предложение остаётся доступным для повтора. Закрытие после ошибки может скрыть его локально без второй записи решения, сохраняя доступ к основному заданию. Несохранённое предложение может появиться на следующем запуске; принятый план восстанавливается по сохранённым данным.

## Совместимость разметки

Пересекающееся оформление нормализуется в корректный HTML с сохранением текста и атрибутов. Сокращение остаётся целым; ссылки и ресурсы не разбиваются. Восстановления получают `repaired_markup` с источником. Структура статей, кодировка, пути ресурсов, лимиты размера/глубины и отмена остаются контролируемыми. Стандартные DSL-теги ударения/дополнительных примеров сохраняют содержимое; неизвестные теги продолжают отображаться как текст с предупреждением.

## Интерфейсы

- `DictionaryReader::relationships(...) -> Result<Option<SourceRelationships>>`: необязательная возможность читателя; стандартная реализация `None` сохраняет совместимость новых модулей форматов.
- `select_primary_dictionary(&[InputBundle], &ReadOptions, &RunContext) -> Result<Option<PrimaryDictionarySelection>>`, где выбор содержит `main_id`, `main_title`, `independent_ids`.
- `JobSnapshot.additional_dictionaries: Option<AdditionalDictionariesOffer>` с `id`, `main_name`, `dictionaries: Vec<InputChoice>`; старые сохранения читаются через `serde(default)`.
- `JobManager::resolve_additional(id, offer_id, convert) -> AppResult<Vec<JobSnapshot>>`; Tauri `resolve_additional_dictionaries`, Vue `resolveAdditionalDictionaries`.

## Приёмка

Синтетические графы проверяют основной/указатель/независимый, неоднозначность, циклы, экранирование и неизвестные форматы. Тесты очереди проверяют согласие, отказ, повтор команды, восстановление, отдельный результат и отсутствие утечки метаданных. Vue/браузер проверяют Dialog, повторные события, ожидание/ошибку, обе темы и минимальное окно. Реальный архив проверяется в изолированном рабочем каталоге без изменения исходника и существующей истории. Сборка macOS — после тестов; мобильные SDK и push не входят в эту работу.
