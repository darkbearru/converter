# Переработка рабочего окна

Источник решения — прямые указания пользователя от 18.10.2026 и image1–image5. Они заменяют прежнюю композицию с левой очередью. Кодовый путь уже выбран; новые макеты и сборки не требуются. Проверки — dev-сервер, тесты и typecheck. Push, запускающий desktop packages, отложен.

Mode: Operate. Пользователь выбирает/перетаскивает источник или скачивает URL, затем отдельно запускает конвертацию. После запуска панель снова принимает следующий файл; задачи поднимаются из-под неё. Завершённые и остановленные задания находятся сверху в Accordion с результатом, активным путём, диагностикой и действиями восстановления.

## Direction contract

THESIS: Рабочее окно по композиции Codex: история сверху, постоянная панель ввода снизу, задачи между ними.

OWN-WORLD: PrimeVue Aura, системная светлая/тёмная тема, системная типографика. Основной оранжевый #F96133 и голубой #65C8EE взяты из book.svg; нейтральные цвета — токены PrimeVue. SVG из предоставленной svg-single.

STORY: Выбрать файл → конвертировать либо ссылка → скачивание → готовый файл → конвертировать. Настройки и ресурсы доступны в Dialog. Результат открывается в ОС по проверенному ID задания.

FIRST VIEWPORT: Изменяемое окно 740×500, компактный заголовок. Без заданий FileUpload занимает всё свободное место. Верхняя область с историей и активными строками растёт по содержимому до70%, оставляя нижней панели минимум30%; история затем прокручивается. При высоте панели до180px содержимое становится компактнее, действия остаются справа. Диалоги укладываются в окно.

FORM: Прямо заданная пользователем композиция image1–image5; прежний seed a332c5d1 больше не определяет layout. Подписи файлов и кнопки остаются читаемыми при длинных именах и масштабировании.

MOTION: Spatial consistency. TransitionGroup, translateY/opacity,240ms cubic-bezier(0.23,1,0.32,1); новые строки выходят из-под панели, старые сдвигаются вверх; reduced motion убирает перемещения.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Уточнения пользователя: конвертация пока имеет отмену и повтор; настоящая пауза нужна только скачиванию. SVG находятся в iCloud Materials/170-thin-line-ui-icons/svg-single. Книга увеличивается на30%, края не обрезаются.

## Уточнение истории — 18.10.2026

Авторитетный снимок пользователя: `/Users/a_abramenko/Desktop/Screenshot 2026-10-18 at 14.35.13.png`. Это узкое расширение существующего Operate-окна: визуальный мир и композиция сохраняются.

Раскрытая запись с предупреждениями показывает одно сообщение с источником/строкой перед результатом. «(ещё N предупреждений)» при наличии остальных — настоящая ссылка с пунктирным подчёркиванием, открывающая отдельный Dialog полного журнала; предпросмотр читает одну запись. Журнал в подробностях активного задания сохраняет страницы по 50. Для готового результата «Открыть папку», «Сохранить копию», «Повторить», «Удалить» стоят одной строкой, путь остаётся отдельным действием ниже.

«Удалить» открывает общий Dialog с текстом «Вы действительно хотите удалить», именем словаря и пояснением о сохранности файлов. Подтверждение удаляет только историю и её журнал: исходники, загрузочный кэш и результаты остаются на диске. Активное задание удалить нельзя. Во время удаления отмена/закрытие/Escape заблокированы; ошибка сохраняет запись. После последней записи панель источника вновь занимает 100% свободного места.

Светлые danger-кнопки уточняют штатные токены Aura: заполненная red600, hover red700, active red800; контурная red700 с унаследованными red50/red100 поверхностями. Контраст: 4,83:1 и 6,20:1. Тёмная тема, оранжевый/голубой книги, иконки и ограничение верхней области 70% / нижней минимум 30% сохранены.

Финальные сравнения: пять снимков и измерения `docs/validation/ui/history-actions`, протокол `docs/validation/history-actions-2026-10-18.md`. Функциональная гонка Escape и единственное замечание finish-review по контрасту исправлены; итоговый вердикт ship. Это браузерная проверка с синтетическими заданиями и подменой нативного ввода/вывода; новая нативная приёмка macOS/Windows не заявляется.

Уточнение компактного вида сохраняет одно предупреждение в истории; доступ к полному списку теперь даёт ссылка в отдельный Dialog. Утилиты ссылки и настроек: кнопка и SVG 24×24px, без рамок/фоновых плашек, промежуток 12px. Локальный `--tool-size` принадлежит `.composer-tools`; базовые иконки-кнопки приложения остаются 32px. Hover, disabled, подписи и клавиатурный фокус сохранены. Три финальных снимка и измерения: `docs/validation/ui/compact-warning`, протокол `docs/validation/compact-warning-2026-10-18.md`; свежий finish-review — ship, замечаний нет. Предлагаемая обработка связанных словарных баз из отдельного исследования архива не входит в реализованное поведение.

Последняя коррекция действий истории: «Открыть папку», «Сохранить копию», «Повторить» и «Уточнить параметры» используют нейтральный secondary outlined (светлая surface600, тёмная Aura surface400). «Удалить» сохраняет красный danger outlined и подтверждение. Четыре кнопки остаются одной строкой; обновлённые снимки и измерения той же группы подтверждают коррекцию. Протокол: `docs/validation/neutral-actions-2026-10-18.md`.

Полный журнал: Dialog «Предупреждения», имя словаря, отдельная прокрутка до 50 записей на странице, штатный Aura Paginator с первой/предыдущей/следующей/последней страницами, текст загрузки и повтор после ошибки. Настоящий anchor имеет согласованные aria-controls/ID и aria-haspopup; закрытие/Escape возвращает фокус после мыши и Enter. Палитра, нейтральный ряд и красный Delete, 24px/gap12 и 100% / 70–30% сохранены. Снимки/измерения: `docs/validation/ui/diagnostics-dialog`; протокол: `docs/validation/diagnostics-dialog-2026-10-18.md`. URL принимает архив либо один словарь; поиска соседей для одиночного URL нет. Объединение баз и изменения парсера из исследования не реализованы этой UI-правкой.
